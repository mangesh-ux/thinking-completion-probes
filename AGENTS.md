# Public research engineering contract

This repository is a publication/reproduction layer for the completed
completion-forecasting study. The separate `reasoning-recovery-probes` workspace
is read-only authoritative historical evidence. Never modify it from this task.

- Keep original recovery measurement failure distinct from the exploratory
  natural-thinking-completion result. Neither correctness recovery nor inference
  savings was established.
- Preserve original cohort, labels, feature definitions, TRAIN folds, selection
  procedure, held-out validation interpretation and reported uncertainty.
- No paid resources, GPU inference, model download, test collection or scientific
  extension may be launched while preparing the publication repository.
- CPU reproduction of existing verified artifacts and synthetic tests is allowed.
  Record exactly what was exercised; mocked tests do not establish real GPU success.
- Do not publish benchmark text, answers, raw reasoning, raw token sequences,
  original problem identities, machine paths, credentials or private archives.
  An explicitly documented anonymized numeric derivative bundle may be released.
- Use separately versioned release schemas and provenance manifests. Keep original
  hashes; never claim anonymized/reformatted files have their original byte hashes.
- Fresh GPU regeneration by future users must be opt-in, write-once, preserve
  failures, keep problem-level splits, and default to TRAIN/VALIDATION only.
  Regenerated stochastic outcomes are not promised byte-identical across hardware.
- Use simple modules, typed interfaces where helpful and synthetic tests. Avoid
  copying obsolete cloud-control machinery or scientific branches into this repo.
